## Rozpoznawanie na podstawie nazwy pliku

Pliki bez rozszerzenia lub o specyficznych nazwach są rozpoznawane automatycznie:

- `Makefile`, `makefile`, `GNUmakefile` → Makefile
- `Dockerfile`, `Containerfile` → Dockerfile
- `CMakeLists.txt` → CMake
- `Rakefile` → Ruby
- `Gemfile` → Ruby
- `Podfile` → CocoaPods
- `Jenkinsfile` → Groovy
- `Vagrantfile` → Ruby
- `Brewfile` → Ruby
- `Procfile` → Procfile
- `.gitignore` → gitignore
- `.gitattributes` → gitattributes
- `.editorconfig` → EditorConfig
- `.env` → Dotenv
- `Cargo.toml`, `Cargo.lock` → Rust
- `go.mod` → Go
- `requirements.txt` → Python
- `setup.py` → Python
- `package.json` → JSON
- `composer.json` → JSON
- `meson.build` → Meson
- `build.sbt` → Scala
- `pom.xml` → Maven
- `build.gradle` → Gradle
- `stack.yaml` → Haskell
- `cabal.project` → Haskell

## Prioritety rozpoznawania

1. **`.gitattributes`** (`linguist-language=`) – najwyższy priorytet, ostatni pasujący wzorzec wygrywa
2. **Nazwa pliku** – rozpoznawanie plików bez rozszerzenia (Makefile, Dockerfile...)
3. **Pełna nazwa ścieżki** – dla plików specyficznych
4. **Rozszerzenie** – standardowe mapowanie rozszerzenia na język
5. **Heurystyka** – np. pliki z "test" w nazwie i rozszerzeniem `.sh` → Shell
